## CRM — 15 áreas principais

1. **Kanban de Deals** — drag-drop entre stages, múltiplos pipelines, filtros, export
2. **Gestão de Pipelines** — criar, reordenar stages, color coding, validações
3. **Detalhes do Deal** — timeline, edições inline, associações a contatos/empresas
4. **Inbox de Leads** — scoring, qualificação, conversão pra deal
5. **Contatos CRUD** — merge, import CSV, export
6. **Empresas** — CNPJ lookup, histórico de interações
7. **Tarefas** — status, prioridade, atribuição, reminders
8. **Email Integration** — OAuth Gmail/Outlook, compor, threading
9. **Campos Customizados** — CRUD, tipos (texto/num/data/select), rendering
10. **Tags** — cores, autocomplete, rastreamento de uso
11. **Lead Scoring** — pesos configuráveis, thresholds
12. **Agendamento** — closer assignment, integração Google Calendar
13. **Permissões** — owner/team/admin
14. **Notificações** — alertas in-app
15. **Analytics básico** — relatórios de pipeline

## AI Agents — 15 áreas principais

1. **Criação de Agente** — wizard 5 steps com templates (Klaus, Iris, Lara, Cassini)
2. **Configuração** — prompt simples/avançado, modelo LLM, tools
3. **Knowledge Base** — upload de documentos, embedding, RAG
4. **Playground de Teste** — chat interface, seleção de canal
5. **Templates pré-built** — Klaus (GMB), Iris (atendimento), Lara (cobrança), Cassini (SDR)
6. **Config de Handoff** — triggers, confidence thresholds, detecção de frustração
7. **Voice (TTS)** — seleção de voz, velocidade, preview
8. **Multimodal** — upload de imagem, áudio (parcial)
9. **Integração CRM** — queries de deal, criar, atualizar
10. **Métricas/Analytics** — conversas, taxa de handoff, CSAT
11. **Logs de Execução** — LLM calls, tool calls, erros
12. **Ambientes** — separação dev/prod (inicial)
13. **Publishing** — ativar/pausar com provisionamento no Frontdesk
14. **Multilíngua** — detecção automática de idioma
15. **Frontdesk Bridge** — provisionamento de bot, handoff de conversa

## Integração entre módulos

- CRM → Frontdesk: CRM Bridge (push de deal data pra custom_attributes da conversa)
- AI Agent → Frontdesk: AI Bridge (provisiona agent_bot via Platform API)
- AI Agent → CRM: tool calls pra query deal, criar deal, atualizar stage
- Handoff (planejado/parcial): Agent detecta necessidade humana → muda status conversa pra `open` + atribui team
